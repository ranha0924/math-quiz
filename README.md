# 이차함수 배움터

> **그래프로 이해하고 유형으로 익히는 고등 이차함수 학습 사이트**

기존 수학 공식 암기 퀴즈를 **이차함수 전문 학습 사이트**로 개편했습니다.
포물선을 직접 움직여 보는 인터랙티브 그래프와, 이차함수 유형별 퀴즈로 구성됩니다.

---

## 구성

### 🧪 그래프 실험실 (`grapher.html`)
`y = ax² + bx + c` 의 계수를 슬라이더로 움직이며 그래프를 실시간 탐구하는 인터랙티브 도구.

- **기본** — 꼭짓점 · 대칭축 · 판별식 D · 실근 · y절편 · 최대·최소
- **직선과의 위치** — 직선 `y = mx + n` 추가, 교점을 연립방정식의 판별식 `D′` 로 판정
- **최대·최소** — 구간 `α ≤ x ≤ β` 에서 꼭짓점 안/밖에 따른 최댓값·최솟값
- **이차부등식** — `>0 / ≥0 / <0 / ≤0` 해 영역 색칠 및 해집합 표시

### 📝 유형별 퀴즈 (`quiz.html`)
학년 구분 대신 **이차함수 8개 유형**에서 랜덤 출제:

이차함수의 그래프 · 판별식과 x축 · 직선과의 위치 관계 · 최대·최소 ·
이차부등식 · 항상 성립할 조건 · 연립이차부등식 · 근의 위치

## 파일 구조

| 파일 | 설명 |
|------|------|
| `index.html` | 랜딩 페이지 (히어로 · 두 기둥 카드) |
| `grapher.html` | 그래프 실험실 (자체 완결형) |
| `quiz.html` | 유형별 퀴즈 화면 |
| `questions.js` | 이차함수 유형별 문제 데이터 |
| `script.js` | 퀴즈 로직 |
| `style.css` | 공용 스타일 (인디고 테마) |

## 기술 스택

- **Frontend**: HTML, CSS, Vanilla JavaScript (프레임워크·외부 의존성 없음)
- **Graph**: HTML5 Canvas (레티나 대응)
- **Deployment**: Vercel
